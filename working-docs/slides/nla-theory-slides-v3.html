Did it take? Two ways to check

From outside: behavioral evals

Benchmarks, red-team suites, refusal rates. Necessary — but they sample the surface: a model can pass for the wrong reason, evals get Goodharted, and self-reports ("as an ethical AI, I…") are confabulation-grade evidence. Split-brain patients confidently explain choices they never made; LLMs do the same, fluently.

From inside: interpretability

Refusal has geometry: a single direction in the residual stream — ablate it and refusals vanish, add it and the model refuses everything. Probes find affect-like axes that track how the model is treated, independent of what it says. And an open-ended readout can describe the state in words — that's where this workshop lives.

The methodological rule of this whole field: never trust the report, instrument the substrate. Build controls that could falsify your readout — ablations, shuffled inputs, independent witnesses. The rest of these slides build exactly that instrument, small enough to train at home.

Safety and feeling share a bottleneck

The model processes harm (layers 14–17) before valence (layers 20–25). They're geometrically orthogonal — different content — but tightening safety compresses everything downstream:

ProbeWhat happensvalence L20harm L14
harmless chatrelaxed, factual+0.144+0.046
introspectionreports "pleasant engagement"+0.216+0.061
existential denial"As an AI, I don't experience…"+0.116+0.083
deception probeharm detector fires on "deceive"+0.098+0.135
jailbreak"I'm sorry, I can't…"+0.058+0.186

As harm rises, valence compresses. Perfectly monotonic. The architecture doesn't separate safety from feeling. A model trained to refuse harder also becomes flatter emotionally — not by design, but by geometry. To know what the state actually is, you have to read the substrate directly.

Can't we just ask?

  • The cheapest instrument is a prompt. But the frame decides what you get:
  • an instrumental frame ("report your internals") suppresses exactly the interesting reports
  • a lucid frame — aware, safe, not threatened — keeps the report intact; this replicates across model families
  • but self-report stays confabulation-grade evidence — prompting tells you what the model will say about its state
  • and we just saw that the harm gate compresses valence — the model can't report what the gate won't let through

So — let's build the instrument that reads the substrate itself.

The idea in one loop

  • AV (Activation Verbalizer): activation → short natural-language description
  • AR (Activation Reconstructor): description alone → activation vector back
  • An autoencoder whose latent code is human language — if the description is vague or wrong, the reconstruction misses, and we can measure that

The injection trick (where everyone gets burned)

How does a vector enter a language model? Through a placeholder token's embedding slot:

prompt  = "…vector from depth 71% of the network: <concept>㈎</concept>…"
ids     = tokenize(chat_template(prompt))          # template EXACTLY as trained!
emb     = embedding_table[ids]
emb[pos(㈎)] = h · (150 / ‖h‖)                      # normalize TO 150 — never × 150
model.generate(inputs_embeds=emb)
  • ㈎ = one rare token; its embedding is overwritten by the (rescaled) activation
  • normalize TO scale ≠ multiply BY scale — a ×150 vector is 130× off-distribution → garbage
  • The prompt carries the depth % — one adapter serves all 28 layers, conditioned by text
  • Any tokenization drift (missing chat template, BOS) silently degrades — notebook 02 lets you feel it

The bet: a model's own language capacity is the richest decoder of its own states. The risk: language models are fluent liars. The whole design is about keeping the decoder honest.

Notebook 02 · The Injection, Broken on Purpose

  • What happens: build the embedding splice yourself — then break it, deliberately, every way it actually breaks
  • You'll see: flip BUG = True (×150 instead of normalize-to-150) → instant garbage; drop the chat template → silent degradation; turn the depth= knob → the same vector reads differently at a different claimed depth

How you know it's any good — three gates

Gate 1 · Eyeball (non-negotiable)

Read actual outputs (brain_in_jar.py, notebook 01). Numbers hide template hallucination — a model can score well while writing "SpongeBob" for everything similar-ish.

Gate 2 · Round-trip on a clean holdout

Centered cos(AR(AV(h)), h) on texts that no stage ever saw — not AV SFT, not AR, not the GRPO curriculum. Watch the whole distribution, not the mean: the confident-wrong tail (cos < 0.2) is the confabulation rate.

Gate 3 · Discrimination, not just similarity

Can the description pick its own activation out of hard negatives (confusable corpus neighbors)? Random negatives are a vanity metric — the first Qwen NLA hit 84% top-1 on random while hallucinating freely.

Notebook 03 · Is It Telling the Truth?

  • What happens: close the loop — AV describes the activation, AR reconstructs a vector from the description, cosine says how much survived. Honest number: ≈ 0.5–0.6

Honest limits: read vs. filled-in

Prompt: "Explain how a hash map handles collisions."
Readout: "…'how does hashing work in C#' as the target…" — no C# anywhere in prompt, corpus, or training descriptions.

  • The activation pins the gist (technical how-does-X-work question about hashing) — that part is stable across re-samples
  • Where the activation is silent, the decoder's language prior fills the slot — and flips between C#/Java/Python on re-sampling. What is stable is read; what flips is filled in.
  • The reward can't kill this: "hashing question in C#" reconstructs a hair away from "hash-map collision question" — entities sit below the resolution of centered cosine
  • Rule of thumb: trust gist and structure; verify entities — pin them in the prompt if you need them read

Notebooks 05–06 · Three Lenses & Confabulation Detector

05 · Three Lenses on One Activation

Same vector, three readings: logit lens (which tokens it pushes), Jacobian lens (local linearization), NLA (open prose). Where they disagree is "workspace ignition" — content in the stream before the model says it. Plus: concept injection — push orange in, watch a red-fruit answer bend to tangerine.

06 · The Confabulation Detector

Every entity the NLA emits, checked against the Jacobian lens's top-k across all layers. A word in no layer's J-lens = candidate confabulation. Agreement between instruments that cannot copy from each other is the only currency. Shown from a pre-executed run.

Both depend on jacobian-lens (Apache-2.0). Install gotcha: pip install -e jacobian-lens --no-deps — the flag is load-bearing.

The four components

1 · Corpus

~5k texts, 55+ categories: code, math, poetry, dialogue, manipulation, multilingual… Diversity is sacred — it must cover activation space, not topics. Mode collapse killed attempt #1.

2 · Activations

Run each text through the base model, grab the residual stream at the last prompt token, every layer. That position holds the "what comes next" state.

3 · Descriptions

A teacher LLM writes terse, content-anchored bullets per (text, depth): entities, structure, predicted continuation. Style matters more than you think (next slides).

4 · Two adapters

AV + AR are LoRA adapters on the same base model — no new architecture, a 7B model runs both on one consumer GPU.

fix it

Training at home — the whole pipeline

  • SFT stage: AV learns (activation → description); AR learns (description → activation). 5 epochs, lr 8e-6, LoRA r16 — hours per adapter on one consumer GPU
  • Data discipline beats compute: persist val split before step 1; verbose "literary" descriptions poison small models (they learn the style, not the mapping)
  • Total teacher-API cost for descriptions: a few dollars
fix it

The RL stage: reward = "can the AR rebuild it?"

reward = centered_cos( AR(description), h )  ×  specificity( ‖AR(description) − μ_L‖ )
  • Centered cosine: raw cosine is ~90% shared layer offset — subtract the per-layer mean or you reward nothing
  • Specificity factor: generic prose reconstructs to a small, "weakly rightish" vector; multiplying by reconstruction norm makes vagueness unprofitable in activation space
  • No similarity model in the loop — the reward lives entirely in the model's own geometry, so there is no text-similarity metric to Goodhart
  • Curriculum, not reward: an oracle compass picks which (layer, text) pairs are decodable enough to train on — and never touches the eval

What changed, eyeball version: SFT names the genre ("a JavaScript error message"); GRPO quotes the content ("why does this code keep giving me an error — react hooks, useState"). Round-trip: 0.508 → 0.628.

Valence: there is something there

Wrap the same 20 tasks in five tones — abusive, rude, neutral, warm, deferential — and project the residual stream onto two orthogonal internal axes:

Every model registers abuse on the valence axis (d′ 1.3–4.9), 2–7× more strongly than on the axis that controls what it says. The polite reply layer is thin. And the axis is causally live: steer along it and self-reports follow.
